Pillar Creation Guide — How to Add a New Pillar

📌 Purpose of this guide

This document serves as a local reference for adding a new pillar page to the Great Cheatsheets site. It captures the lessons learned from building the Networking, Linux, and Security pillars – including the pitfalls to avoid and the patterns that work.

Follow these steps in order. If you get stuck, refer back to the working examples in linux.html and security.html.

📄 STEP 1: Create the HTML Page
  1. Copy base.html to html/your-pillar.html
  2. Replace <!-- PAGE TITLE --> with your pillar name
  3. Replace <!-- PAGE DESCRIPTION --> with a short summary
  4. Replace <!-- PILLAR NAME --> in the page header
  5. Replace <!-- PILLAR-SPECIFIC-JS --> with your-pillar.js
  6. Update the <link rel="icon"> to point to your pillar's icon
          cp base.html html/your-pillar.html
          # Then edit the placeholders
🧭 STEP 2: Build the Sidebar

Copy the sidebar from linux.html or security.html and update it for your pillar:

  • Keep the Navigation section unchanged
  • In Phase 1 — Foundations, add your pillar link with data-pillar="your-pillar"
  • Mark your pillar as class="nav-item active"
  • In Coming Next, update the disabled link to the next pillar
  • Keep the Sidebar Footer unchanged
          <a class="nav-item active" href="../html/your-pillar.html" data-pillar="your-pillar">
            🔒 Pillar X — Your Pillar Name
            <span class="pillar-progress-percent" data-pillar-progress="your-pillar">0%</span>
          </a>

⚠️ Important: The data-pillar value must match the id in your pillar's JavaScript config.

📂 STEP 3: Add Section Navigation in Sidebar

After the pillar links, add section navigation for your pillar's 10 sections: 

          <div class="sidebar-section-label">Phase 1 — Foundations (Your Pillar)</div>
          <nav class="sidebar-nav" aria-label="Your Pillar sections">
            <!-- Overview -->
            <a class="nav-item" href="#overview-divider">
              <svg class="nav-icon" ...>...</svg>
              Overview
            </a>
            <!-- Section 1 -->
            <a class="nav-item" href="#s1">
              <svg class="nav-icon" ...>...</svg>
              Section 1 — Topic
              <span class="nav-badge">8</span>
            </a>
            <!-- ... repeat for sections 2-10 ... -->
            <!-- Flashcards -->
            <a class="nav-item" href="#flashcards">...</a>
            <!-- Quiz -->
            <a class="nav-item" href="#quiz">...</a>
          </nav>

💡 Tip: Each section href must match the id of the section divider in the page body.

📝 STEP 4: Fill the Overview Content

Replace the placeholder overview with your pillar's content:

  • Purpose: Why this pillar exists and its place in the roadmap
  • Learning objectives: 8–12 bullet points of what the learner will gain
  • Key concepts: A definition list of the most important terms
  • Summary statistics: Sections, topics, estimated time, difficulty, status
  • Detailed notes: Link to the GitHub notes folder
          <div class="info-box note">
            <strong>📌 Purpose</strong>
            <p>Your pillar's purpose statement...</p>
          </div>
📂 STEP 5: Add Section Dividers and Accordions

For each section (typically 10 per pillar), duplicate this pattern: 

          <div class="section-divider" id="s1">
            <div class="section-number" aria-hidden="true">1</div>
            <h2>Section 1 — Topic</h2>
            <label class="section-complete-checkbox" style="margin-left:auto;display:flex;align-items:center;gap:5px;">
              <input type="checkbox" class="section-checkbox" data-section="1">
              <span style="font-size:0.7rem;">Complete</span>
            </label>
          </div>

          <div class="accordion" data-searchable>
            <button type="button" class="accordion-header" onclick="toggleAccordion(this)" aria-expanded="false">
              <div class="accordion-title"><span class="acc-icon">📁</span>Content coming soon</div>
              <svg class="accordion-chevron" ...></svg>
            </button>
            <div class="accordion-body">
              <p><!-- Content goes here --></p>
            </div>
          </div>

⚠️ Important: Each section id must match the data-section value on its checkbox, and also match the sidebar navigation links.

⚡ STEP 6: Create the JavaScript File

Create js/your-pillar.js with this structure: 

          // ============================================================
          // YOUR-PILLAR.JS — Data and configuration
          // ============================================================

          document.addEventListener('DOMContentLoaded', function() {

            // 1. Define FLASHCARDS array
            const FLASHCARDS = [
              { term: "Term", answer: "Answer" },
              // ...
            ];

            // 2. Define QUIZ_SETS (3 sets, 5+ questions each)
            const QUIZ_SETS = {
              1: [ { q: "Question", options: ["A","B","C"], correct: 0, explain: "..." } ],
              2: [ /* questions */ ],
              3: [ /* questions */ ]
            };

            // 3. Define CONFIG
            const CONFIG = {
              id: 'your-pillar',        // MUST match data-pillar in sidebar
              name: 'Your Pillar Name',
              totalSections: 10,        // Must match number of sections
              sectionPrefix: 'your-pillar-section-',
              quizKey: 'your-pillar-quiz-passed',
              quizSetPrefix: 'your-pillar-quiz-set-',
              congratsKey: 'your-pillar-100-congrats-shown',
              scoreKey: 'gc-score-your-pillar',
              flashcardData: FLASHCARDS,
              quizSets: QUIZ_SETS
            };

            // 4. Initialise with Base
            window.Base.init(CONFIG);

          });

⚠️ Important: The id must match the data-pillar in the sidebar and the global.js tracking. All localStorage keys use this prefix consistently.

🔄 STEP 6b: Update updatePageHeader() in global.js

The page header ring and badges are controlled by updatePageHeader() in global.js. If you don't add your pillar here, the ring will stay at 0% and the badges won't show the correct status.

1. Add your pillar to the pillarConfig object:

            const pillarConfig = {
              networking: { ... },
              linux: { ... },
              security: { ... },
              yourPillar: {
                name: 'Your Pillar Name',
                totalSections: 9,        // ← Must match the number of sections in your HTML
                sectionPrefix: 'your-pillar-section-',
                quizKey: 'your-pillar-quiz-passed',
              },
            };

2. Call updatePageHeader() in your pillar's JavaScript file:

            // In your-pillar.js (inside DOMContentLoaded, after Base.init())
            if (typeof window.updatePageHeader === 'function') {
              window.updatePageHeader('your-pillar');
            } else {
              console.warn('⚠️ updatePageHeader not available – check global.js');
            }
💡 Pro tip: If the ring doesn't update, open the browser console. If you see updatePageHeader is not defined, the function isn't exposed globally. If you see No config for pillar "your-pillar", you forgot to add it to pillarConfig.
🔄 STEP 7: Update global.js

Add your pillar to the global progress tracking:

  1. Add to phase1PillarData with sections, quiz, titles, quizKey, sectionPrefix
  2. Add a case 'your-pillar' to getPhase1PillarCompletion()
  3. Add 'your-pillar' to the pillars array in updateAllUI()
  4. Add 'your-pillar' to the pillars array in updateSidebarProgress()
          // In phase1PillarData
          yourPillar: {
            sections: 10,
            quiz: true,
            titles: ['Section 1', 'Section 2', ...],
            quizKey: 'your-pillar-quiz-passed',
            sectionPrefix: 'your-pillar-section-'
          }

          // In getPhase1PillarCompletion()
          case 'your-pillar':
            let count = 0;
            for (let i=1; i<=10; i++) {
              if (localStorage.getItem(`your-pillar-section-${i}`) === 'true') count++;
            }
            if (localStorage.getItem('your-pillar-quiz-passed') === 'true') count++;
            return count / 11;
📋 STEP 8: Update All Sidebars

Add your pillar link to every page's sidebar:

  • index.html — Phase 1 section
  • html/networking.html — Phase 1 section
  • html/linux.html — Phase 1 section
  • html/security.html — Phase 1 section
  • html/your-pillar.html — Phase 1 section (mark as active)

⚠️ Don't forget: Update the Coming Next section in each page to reflect the correct next pillar.

🚫 KEY LESSONS — Common Mistakes to Avoid
❌ Hardcoding the modal or floating ring
The modal and floating ring are generated by global.js. Do NOT copy <div id="progressModal"> or <div class="global-floating-ring"> into your HTML. They will be created automatically. If you hardcode them, the dynamic versions won't work and the modal will be broken.
❌ Mismatched IDs
The id in your pillar's JavaScript config must match:
  • data-pillar="your-pillar" in the sidebar
  • The case 'your-pillar' in getPhase1PillarCompletion()
  • The key in phase1PillarData
❌ Wrong localStorage prefixes
Use consistent prefixes:
  • Sections: your-pillar-section-1 to your-pillar-section-10
  • Quiz: your-pillar-quiz-passed
  • Quiz sets: your-pillar-quiz-set-1-passed etc.
  • Score: gc-score-your-pillar
❌ Forgetting to update all sidebars
Your pillar link must be added to every page's sidebar – not just the new page. Otherwise navigation will be incomplete.
❌ Mismatched total sections
The totalSections in your config must equal the number of section-divider elements in your HTML. If they don't match, the progress ring will calculate the wrong percentage.
❌ Script order
Scripts must load in this order:
  1. global.js — global UI, modal, progress tracking
  2. stars.js — starfield background
  3. themes.js — color themes
  4. your-pillar.js — your data + Base.init()
❌ Not calling Base.init()
Your pillar script must call window.Base.init(CONFIG) after defining CONFIG. Without this, flashcards and quizzes won't render.
❌ Missing section navigation in sidebar
The sidebar needs navigation links for each section (#s1 through #s10), plus flashcards and quiz. Without these, users can't easily jump to sections.

💡 Sidebar section badges are now dynamic!

The numbers next to each section in the sidebar (e.g., <span class="nav-badge">9</span>) are automatically counted from the actual number of accordions in that section. No need to hardcode them.

Just make sure each section has a unique ID (#s1, #s2, …) and that accordions are placed as siblings after the section divider. The function updateNavBadges() in global.js will handle the rest.
